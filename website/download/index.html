Download FAQ

Is this really free?

Yes. RouterConfig Pro is free and open source under the MIT license. No accounts, no licensing server, no telemetry — install and use it.

Why does it run its own backend?

The app bundles a local FastAPI service (on 127.0.0.1) plus an Electron shell. This gives you a real web API and a clean desktop UI over the same engine — and keeps router traffic on your machine.

Is it safe to run?

It binds only to localhost, requires an API token on every request, and stores credentials encrypted. Because it's unsigned on first release, Linux may warn you: allow the AppImage or install the DEB, and verify the SHA-256 checksum published at release.

Which routers work?

Ubiquiti (EdgeOS), MikroTik (RouterOS), TP-Link (LUCI/forms) and any generic SSH device. See the README for the full vendor matrix.

How do updates work?

Download the new build from this page whenever you want. Your devices, configs and settings stay exactly where they are.

Will Windows be available?

Windows (NSIS) and macOS builds are planned. In the meantime the source runs anywhere Python and a browser do.
