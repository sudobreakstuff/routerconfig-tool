Privacy Policy

Effective August 2026

What RouterConfig Pro collects

Nothing. RouterConfig Pro is a local-first application. It runs entirely on your machine and performs no telemetry, analytics, crash reporting or usage tracking.

Where your data lives

All application data — your device list, connection profiles, templates, and settings — is stored on your own computer in a local data directory (RC_DATA_DIR, default ~/.routerconfig/). No copy of this data is sent to us or to any server controlled by us.

Device credentials and secrets

Router credentials, connection profiles, and ISP API keys are stored locally in an encrypted form (Fernet). The API exposed by the local backend is protected by a per-install token and is only reachable from the local app origins.

What the app connects to

RouterConfig Pro connects only to the devices and services you explicitly configure: the SSH endpoints of your own routers, and any ISP inventory service you opt into for device uploads. It does not make background connections to us.

GitHub Pages site

This website is served statically from GitHub Pages. It loads fonts from Google Fonts; those requests are subject to Google's privacy policy. The site itself does not set cookies or run tracking scripts.

Changes

If this policy changes, the effective date above will be updated. Since the app is open source, you can audit exactly what it does at any time.

Contact

Questions or concerns? Open an issue on the GitHub repository.
